# 《实验2610》开源方法试用（二）：RDM风险分布匹配

**目标**：先试用作者已有方法，了解其在本项目老年认知健康预测中的表现；当前不追求严格的论文复现、多种子显著性证明或全套优化器/网络一致性消融。

## 1. 官方来源与保留内容

- 论文：Nguyen, Toan et al., *Domain Generalisation via Risk Distribution Matching*, WACV 2024
- 论文地址：https://openaccess.thecvf.com/content/WACV2024/html/Nguyen_Domain_Generalisation_via_Risk_Distribution_Matching_WACV_2024_paper.html
- 官方仓库：https://github.com/nktoan/risk-distribution-matching
- 源码固定版本：`1b8830e1b373ccacc7b50a2089ebfc2c188bb6b2`
- 核心算法来源：`DomainBed/domainbed/algorithms.py` 的 `class RDM`
- 原许可证：MIT，见 `project/external/RDM_LICENSE.txt`
- 本地适配：`project/src/elderly_health/rdm_adapter.py`，独立入口：`project/run_external_rdm.py`

直接沿用作者核心操作：每环境抽取批次、按环境求样本平均风险并找最差环境、将其逐样本损失与全部环境的逐样本损失用八个带宽的高斯MMD匹配、可选方差惩罚、退火后开启匹配、在退火切换点重设Adam优化器。

**不得称为完全原样复现**：为了使用19维表格特征，输入网络为本项目`SimpleMLP`；任务从作者的图像多分类改为带正例权重的二分类BCE；保留项目既有训练集拟合预处理、来源验证集选择最佳模型、LORO划分；移除了`.cuda()`硬编码，使用CPU。作者的图像网络、批次/随机种子/模型选择协议及数据集全部不同。

探索性默认超参数中，`rdm_lambda=5.0`、`rdm_penalty_anneal_iters=1500`、`rdm_lr=1.5e-5`参考官方DomainBed参数注册表的部分数据集起始配置；`variance_weight=0`保持简化的主要MMD项。`positive_weight=3.0`、300轮、每环境32条、每轮源数据均衡抽样和第91轮后选模是本项目适配设置，不是作者论文规定的本数据最佳值。不同损失的规模和类别分布可能使其表现与原论文差别很大。

## 2. 实际执行步骤

请在本地仓库根目录运行；先检查是否有未提交的本地改动，再切换分支：

```bash
git fetch origin
git switch feature/experiment2610-open-source-baselines
git pull --ff-only origin feature/experiment2610-open-source-baselines
git lfs pull
python -m unittest discover -s tests -v
python -m compileall -q project/src/elderly_health project/run_external_rdm.py
```

先仅留出东部，检查加载、CPU训练与输出文件是否正常（仅3轮，没有研究意义）：

```bash
python project/run_external_rdm.py --mode loro --held-out east --epochs 3 --selection-start-epoch 1 --rdm-penalty-anneal-iters 2 --output outputs/external-rdm-smoke-east-42
```

如果测试、试运行均成功，再直接运行三个地区的初步试用：

```bash
python project/run_external_rdm.py --mode loro --environment-granularity region --output outputs/external-rdm-region-loro-42
```

如有需要，也可以额外把剩余8个站点当训练环境（仍是留一地区），探索RDM在较多训练环境下的表现，但现在**不要求执行**：

```bash
python project/run_external_rdm.py --mode loro --environment-granularity site --output outputs/external-rdm-site-loro-42
```

注意输出目录必须不存在，否则程序会拒绝覆盖。首次完整运行CPU可能较慢，且会运行三套独立模型；请不要把3轮试运行的结果放进论文统计表。

## 3. 查看与解读结果

本次使用同一批样本、同样的东中西划分，可初步对照已有的：

- `outputs/v2-region-loro-selection91-42/summary.csv`（V2和MLP）
- `outputs/v2-site-loro-selection91-42/summary.csv`（V1）
- `outputs/external-vrex-region-loro-42/summary.csv`（VREx）
- 新增 `outputs/external-rdm-region-loro-42/summary.csv`（RDM）

只看每地区AUC、AUPRC、Brier、F1、Recall，及平均指标的趋势。VREx和RDM即使指标不同，也不能全部归因于两个损失函数：原论文算法与适配还存在训练和优化差异。尤其不同地区阳性比例差别明显，使用加权BCE会改变风险分布。RDM不直接识别年龄、手机使用等因素的因果效应，不含V5的两个因果/环境分支。

`training.json`还会输出按epoch统计的`matching_penalty`、`matching_weight`以及最佳验证AUC，可检查MMD项是否在退火后启用；`config.json`保存官方来源SHA、算法调整和输入数据SHA256，便于追溯。

本阶段代码已直接提交GitHub，**尚未在用户本地Python3.10/PyTorch2.4.1环境与真实数据上完成运行验证**。请先跑测试，有任何错误保留终端输出。原始调查数据、预测逐行结果和模型可能涉及敏感信息，上传到公开GitHub前确认有相应授权与去标识化处理。
