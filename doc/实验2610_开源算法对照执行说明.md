## 第一个实现：DomainBed VREx 表格数据适配（不是原论文完整复现）

- 方法来源：[facebookresearch/DomainBed](https://github.com/facebookresearch/DomainBed) 的 `domainbed/algorithms.py` 中 `VREx` 类
- 固定源版本：[b93c22a1](https://github.com/facebookresearch/DomainBed/blob/b93c22a1cfc3b2428398272c1a116c8de1f4139e/domainbed/algorithms.py)
- 源项目 MIT 许可，保留 `project/external/DOMAINBED_LICENSE.txt`
- 算法思想：各训练环境损失的均值，加环境间损失方差作为惩罚；训练更新前按源代码的退火规则取权重，退火切换点重置 Adam
- **适配之处：** 19维数值输入、项目自己的 `SimpleMLP` 单输出二分类头、带正例权重的 `BCEWithLogitsLoss`、CPU、环境均衡小批次、原项目划分和预处理、第91轮开始选最佳权重。这些改变都使它不等同于原图像域泛化论文的完全复现。
- 默认 `vrex_lambda=10`、`penalty_anneal_steps=500` 参照 DomainBed 配置；其它训练参数为适配本项目预先设定的起点，不是通过测试结果选择的最优值。
- 不直接拷贝原项目的 ResNet/图像数据加载器，不混用任何 V5 的因果门控或独立性损失。

## 先本地验证

在新分支、仓库根目录执行：

```bash
git switch feature/experiment2610-open-source-baselines
git pull --ff-only origin feature/experiment2610-open-source-baselines
git lfs pull
python -m unittest discover -s tests -v
python -m compileall -q project/src/elderly_health project/run_external_vrex.py

# 小规模冒烟测试（不构成正式论文实验）
python project/run_external_vrex.py --mode loro --held-out east --epochs 3 --selection-start-epoch 1 --penalty-anneal-steps 2 --output outputs/external-vrex-smoke-42
```

冒烟测试通过后，再运行官方对照。选择 region 是为了与完成的 V2 三地区模型比对：

```bash
python project/run_external_vrex.py --mode loro --environment-granularity region --output outputs/external-vrex-region-loro-42
```

若要补充站点环境训练对照，使用同样算法并且不改变其他设置：

```bash
python project/run_external_vrex.py --mode loro --environment-granularity site --output outputs/external-vrex-site-loro-42
```

每次LORO自动留出east/central/west三个完整地区，分别训练一个VREx模型；
`summary.csv`汇总各地区测试AUC、Average Precision（输出名为auprc）、Brier、F1等；
各折还会保存训练信息、模型权重、预处理参数、预测概率及输入文件SHA256。
原V5和MLP对照已有在旧分支，直接用原来的结果进行同地区对照，无须重复训练。
本入口拒绝写入已存在的输出目录。

**目前只有代码和合成数据测试，没有在用户真实调查数据上完成 VREx 正式训练或性能验证。**
单次seed42仅为初步比较，不能以固定测试集的少量改善宣称方法有效。
生成的预测CSV及模型文件可能含有敏感调查信息；提交公开仓库之前须核实数据授权与去标识化程度。
