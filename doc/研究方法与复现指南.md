# 研究方法与复现指南

> 面向已完成的《实验2610》：本文件合并了代码清理、V1门控、V2环境粒度、选模诊断与外部方法试用的原分散说明。实际结果见[阶段总结](实验2610_阶段性总结_20261021.md)。

## 1. 数据与代码整理（研究起点）

- 主流程只处理**4,769条有效认知功能标签、19个输入特征**；历史151特征探索、PC/NOTEARS等因果发现脚本不在本次统一重构范围。
- `project/run.py`和`project/src/elderly_health/`分别为统一CLI及数据、模型、损失、训练、评价模块；旧入口见`project/legacy/`与兼容包装。
- 修复：**先划分后预处理**（每折只用训练集拟合中位数填补和标准化）；最佳权重从验证集选中轮次保存并恢复；MLP使用logits计算BCE；固定Python/NumPy/PyTorch种子；统一标签1/2到0/1；校正图角色判定和梯度；样本原始行号`sample_id`可跨输出对齐。
- 这些行为修复可能改变历史AUC，所以旧结果与清理后结果不能当作只修改单个超参数的直接对照。
- 默认输入文件：`project/data/data_mission2.csv`（GBK），本阶段各主要实验输入SHA256：`969f0c1c82faafcfa402f37572e4a8ceb324492062cf1e590465f82dc6b5b6de`。

### 两种外部验证

|方式|训练/验证与测试关系|主要用途|
|---|---|---|
|随机70/15/15|来自相同站点集合；3337/716/716|基本预测与模型结构检查|
|LOEO（12站点）|每轮留出1个完整监测点，12轮宏平均|检查跨站点预测|
|LORO（3地区）|每轮完整留出1个地区，3轮宏平均|检查跨地区预测|

LOEO和LORO各折仅在来源样本中进一步划出验证集，并独立拟合预处理。宏平均是**各留出单位等权平均**，不是把所有人汇总计算一次AUC；两种宏平均单位不同，不能直接用其高低判定难度。

地区依据原实验2610约定：`11`北京、`37`山东→east；`22`吉林、`36`江西→central；`45`广西、`64`宁夏→west。环境码由站点码前两位导出，环境不是模型预测输入。省份分组应以调查设计说明为准。

## 2. 现有V5模型（V1/V2共同基础）

输入`X`（19维数值编码）通过连续门控`g=sigmoid(5m)`分配为`X_c=X*g`与`X_s=X*(1-g)`，再分别编码为`z_c`、`z_s`：

- 主头：V5拼接`[z_c,z_s]`预测认知功能受损。
- 辅助头：从`z_c`预测标签；`z_s`有环境分类器。
- 训练正则：预测损失、均值或目标稀疏、极化、可选图先验、自定义IRM（v11）、环境分类、HSIC统计依赖惩罚。
- 约束随轮次渐增；`irm_start=50`、`ramp_epochs=40`时第91轮起不变性约束达到完整强度。

**解释边界：** `z_c`被设计为希望更稳定的预测表示，不是已识别的因果表示；`z_s`希望包含环境信息，也未证明两者完全独立。v11为项目自定义梯度方差惩罚，并非严格标准IRMv1；`lambda_entropy`实际作用在`g(1-g)`极化项，而非Shannon熵。`g>0.5`只用于展示特征，不切断其他特征输入。

## 3. V1：软门控限制与第91轮选模诊断

**研究问题：** 图先验、要求接近五个特征的稀疏目标，以及较强的门控极化是否阻碍了特征学习？

- 关闭图先验（`lambda_graph=0`）；采用均值软稀疏（`sparsity=mean`），不强制选择5特征。
- 极化项权重对照为0/3/30；双分支、IRM与HSIC不因此同时改变。
- 对于提前出现验证AUC峰值的问题，增加`selection_start_epoch=91`：前90轮照常训练，但不能被选为最佳模型。选模窗口改变也可能改变早停总训练轮数。

### 门控与选模结果（seed=42，716人同一随机测试集）

|极化权重|选模窗口|最佳轮次|AUC|AP/AUPRC|门控>0.5特征数|
|---|---|---:|---:|---:|---:|
|0|原策略|68|0.74046|0.36012|4|
|0|第91轮起|111|0.73820|0.35716|3|
|3|原策略|111|0.73941|0.36096|5|
|3|第91轮起|111|0.73941|0.36096|5|
|30|原策略|54|0.74406|0.39699|10|
|30|第91轮起|188|0.74203|0.39025|10|

这些结果不支持“门控越极化越有因果意义”，也未显示延后选模有明确性能收益。高权重特征如年龄、财富或手机使用只代表模型关联，不是干预结论。第91轮策略是由训练时序预先确定，不是用测试集挑选参数。

对应配置：`v1_relaxed.json`，以及`v1_full_polar{0,3,30}.json`等历史保留预设；结果在`outputs/v1-*/`下。

## 4. V2：环境粒度与验证路线

**假设：** 相比12个细粒度监测点，把数据定义为东、中、西3组，可能更稳定地计算环境约束。

- V1/site和V2/region只改变模型的环境标签与有关损失的分组；19个输入特征与目标不变。
- 完整约束阶段的两个主要配置：`project/configs/v2_site_v1_selection91.json`与`project/configs/v2_region_v1_selection91.json`。
- 顺序：随机同源测试 → 完整12站点LOEO → 完整3地区LORO。
- 详细数值和结论见[阶段总结](实验2610_阶段性总结_20261021.md)。

## 5. 开源论文方法的CPU表格适配

以下方法**没有V5的CausalGate或`z_c/z_s`因果解耦双分支**。它们作为域泛化/鲁棒优化的外部探索方法，统一使用本项目的19维`SimpleMLP`、来源数据切分与验证选模，但分别保留原作者的核心惩罚或组风险更新。适配影响与原论文的可比性，不能称为完整原实验复现。

|方法|官方源代码/版本|保留的机制|本地文件|
|---|---|---|---|
|VREx|[DomainBed](https://github.com/facebookresearch/DomainBed) `b93c22a1...` (MIT)|多环境平均风险方差惩罚、退火和Adam重置|`vrex_adapter.py`、`run_external_vrex.py`|
|RDM|[RDM WACV2024](https://github.com/nktoan/risk-distribution-matching) `1b8830e1...` (MIT)|选最差平均风险环境，多带宽高斯MMD匹配其与全部样本损失分布，退火和Adam重置|`rdm_adapter.py`、`run_external_rdm.py`|
|GroupDRO|[GroupDRO ICLR2020](https://github.com/kohpangwei/group_DRO) `cbbc1c5b...` (MIT)|按组损失乘法更新权重，再最小化加权组风险|`groupdro_adapter.py`、`run_external_groupdro.py`|

源项目MIT许可原文位于`project/external/`。本项目适配用CPU、加权二元BCE（默认正例权重3）、每训练环境32条均衡小批次、第91轮后验证AUC选模。原论文图像/文本网络、抽样/学习率配置不等于我们的实现，所有差异都应视为探索性适配的重要限制。

## 6. 复现命令及结果索引

从仓库根目录执行，确保使用Python3.10与PyTorch CPU环境：

```bash
python -m pip install -r requirements.txt
git lfs pull
python -m unittest discover -s tests -v

# 随机划分
python project/run.py train --config project/configs/v2_site_v1_selection91.json --output outputs/recheck-site-42
python project/run.py train --config project/configs/v2_region_v1_selection91.json --output outputs/recheck-region-42

# 留一站点（12折）
python project/run.py loeo --holdout-level site --config project/configs/v2_site_v1_selection91.json --output outputs/recheck-site-loeo-42
python project/run.py loeo --holdout-level site --config project/configs/v2_region_v1_selection91.json --output outputs/recheck-region-loeo-42

# 留一地区（3折）
python project/run.py loeo --holdout-level region --config project/configs/v2_region_v1_selection91.json --output outputs/recheck-v2-loro-42
python project/run_external_vrex.py --mode loro --output outputs/recheck-vrex-loro-42
python project/run_external_rdm.py --mode loro --output outputs/recheck-rdm-loro-42
python project/run_external_groupdro.py --mode loro --output outputs/recheck-groupdro-loro-42
```

## 7. 现存限制与未来研究建议（未完成事项）

1. 已完成实验主要是单种子42；未进行多种子统计验证或完全独立调查队列复核。
2. LOEO中模型已见/未见环境的探针统计并不能直接证明表示解耦；LORO未见地区的探针多为`null`是标签未见，并不等于去除环境信息。
3. 自定义IRM、HSIC、图先验、门控极化对外部泛化的独立作用仍缺完整消融；RDM/VREx/GroupDRO之间也非严格只差一个损失项。
4. 不同地区的阳性率不同，按地区匹配总体预测损失分布可能同时反映类别比例差异。
5. 没有通过干预、工具变量、纵向识别或敏感性分析验证任何健康变量的因果效应。过去研究设想中的`z_c`聚类表型、干预推荐和临床决策支持目前均**未开展**。
6. 项目现有旧实验和历史分析可以从Git整理前提交`38a77cf`恢复，本轮清理仅合并Markdown，不移除实验代码、实验配置或原始输出。
