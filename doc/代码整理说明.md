# 代码整理与行为变更说明

本次将目前使用的19特征训练、预处理和LOEO流程集中到 `elderly_health` 包。
早期151特征探索和因果发现算法保留原样；不宣称已经修复所有历史脚本。
数据文件、旧权重、实验记录及原有结果没有修改。旧入口源码快照在 `project/legacy/`。

## 格式与结构

- 统一职责、入口、配置、类型清晰的图角色和UTF-8文本。
- 去掉主流程重复模型定义及不必要的networkx依赖。
- 导入模型/训练模块不再自动读取数据、选择设备或创建输出目录。
- 默认CPU，种子真实设置为Python、NumPy和PyTorch随机种子。
- 每次实验独立输出，不覆盖 `best_params.json` 或旧实验CSV。

## 会改变结果的修复

| 修复 | 旧行为 | 新行为 |
|---|---|---|
| 预处理泄漏 | 全数据填充、标准化后划分 | 先划分，仅训练集拟合；LOEO每折独立拟合 |
| 图损失 | 数值先验与字符串判断不匹配，可能恒为0 | 统一角色字符串，父节点有有效梯度，非法角色报错 |
| 图角色 | 注释声称识别混杂，但代码未实现路径判断 | 只标记父、子、无直接边，不声称识别混杂 |
| 最佳权重 | 部分分支仅记最佳AUC，却返回最后一轮模型 | 所有训练使用内存快照，返回最佳验证权重 |
| 调度损失 | 部分MLP把Sigmoid概率送入Logits损失 | 训练和验证均把原始logits送入BCEWithLogitsLoss |
| 随机性 | 导出seed=42但未固定训练随机源 | 固定真实种子并记录依赖版本 |
| ID和标签 | 每个划分重新编号；原始1/2与导出0/1混用 | 保留CSV原始行号，新文件显式0/1标签元数据 |
| 环境探针 | 未报告无训练标签的测试环境或基线 | 报告已见/未见数量、平衡准确率及多数类基线 |
| 手机缺失 | 一概填0，可能把未知视为不使用 | 延续原CSV现有0编码，新增缺失按训练中位数填充 |
| 配置问题 | 大量全局变量、导入时读取固定数据 | JSON配置验证、显式参数、每轮损失记录 |

标准IRM仍用未加类别权重的环境BCE，主预测用加权BCE，沿用旧V5设计。
需要比较类别权重是否应统一时，另立实验，不能混入代码清理结果。
单类测试环境的AUC记为null；AUPRC字段实际使用sklearn的Average Precision。
重复运行的差异和历史AUC变化不能归因于单个方法模块，修复后必须重新建立基线。
