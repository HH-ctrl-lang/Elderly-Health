# 《实验2610》阶段性总结（2026-10-21）

## 一、任务范围和阶段判断

根据《实验2610.docx》，本轮主要目标有二：

1. **V1 门控放松**：撤去因果图的强先验约束；不强制必须选五个变量，以软稀疏和连续门控替代硬筛选；在双表示结构、IRM/HSIC基本不变条件下检查约束影响。
2. **V2 环境粒度**：把建模环境从12监测点改为研究定义的东、中、西三地区；在现有框架开展实验，并选用有公开代码的论文方法，在同一健康数据任务上试跑。

这两个目标的**探索性实验任务目前均有对应代码与结果，建议本阶段收尾**。
尚未完成的多种子检验、外部独立队列、严格算法消融、因果效应识别均不属于“已证明的结论”；如未来继续深入，应另列研究阶段，勿混入本次实验成果。

## 二、数据与测试设计

- 数据：有效标签共4,769人、19个输入特征。
- 地区：东部（北京、山东）；中部（吉林、江西）；西部（广西、宁夏），这是按原实验文档确定的**项目分组**，不宣称通用行政地理分类。
- LORO：每次完整留出1个地区，训练时只有其余两地区，测试人数东部1,570、中部1,598、西部1,601。
- 所有列出的外部开源算法结果、V5、MLP均来自已上传的`summary.csv`，使用相同输入文件SHA256
  `969f0c1c82faafcfa402f37572e4a8ceb324492062cf1e590465f82dc6b5b6de`。
- 对比的三个外部地区样本ID和标签经逐行核对一致；宏平均即三个留出地区等权平均。

## 三、方法与代码来源

|方法|目标机制|实现来源|
|---|---|---|
|MLP|普通二分类预测|项目 `SimpleMLP`|
|V1（site）|软门控/双表示/IRM/HSIC，12站点作为训练环境|项目 `v2_site_v1_selection91.json`|
|V2（region）|同上，东中西3地区作为训练环境|项目 `v2_region_v1_selection91.json`|
|VREx|惩罚各环境**平均损失的方差**|facebookresearch/DomainBed, commit `b93c22a1cfc3b2428398272c1a116c8de1f4139e`|
|RDM|用多带宽核MMD匹配最差环境和整体**样本损失分布**|nktoan/risk-distribution-matching, commit `1b8830e1b373ccacc7b50a2089ebfc2c188bb6b2`|
|GroupDRO|增大训练中高损失环境的动态权重|kohpangwei/group_DRO, commit `cbbc1c5b06844e46b87e264326b56056d2a437d1`|

上述外部方法是作者核心算法的**CPU表格二分类适配**，使用本项目`SimpleMLP`、相应损失与固定选模策略，不是作者图像/文本实验的完整复现。
RDM、VREx、GroupDRO都是域泛化/鲁棒优化方法，**不直接识别任何健康变量的因果效应**。

## 五、对结果的解释

1. **RDM在当前探索性结果中综合最积极**：三地区宏平均AUC 0.7276、AUPRC 0.3127、Brier 0.1379均为本组最好，东部AUC 0.6982、AUPRC 0.3245也具有优势；但中西部不一定最优。
2. **VREx强调召回，但概率误差更大**：宏平均F1 0.3680、Recall 0.5265最高，Brier 0.1653偏大。固定0.5阈值下表现不等于输出概率已经充分校准。
3. **GroupDRO并未整体胜出**：宏平均AUC 0.7131比MLP略低，AUPRC 0.3007高于MLP；中部AUPRC 0.2316、Brier 0.1308为本组最好，但其余地区没有同步提高。
4. **GroupDRO权重变化值得记录**：留出西部时，最佳轮次的两个训练组`central/east`权重为0.0283/0.9717，几乎集中在东部。它优化的是**源域训练组**，不保证改善一个未见的西部地区。这解释了为何“关注困难训练组”不能自动变成更好的外部泛化。
5. **前序环境粒度试验的负结果同样保留**：随机划分V2略优于V1，但完整12站点LOEO中这种优势基本消失；LORO中V1/V2宏平均也极为接近，不能宣称环境粒度修改带来了稳定提升。
6. **模型选择无明显违规**：GroupDRO最佳轮次东247、中157、西92，都不早于要求的第91轮；三折的输入数据指纹相同。

## 七、下一阶段如何启动

本阶段优先归档，不继续无限堆砌开源模型，也不回退已有结果。

后续若要正式研究因果表征有效性、多种子外部泛化、IRM/HSIC解耦消融等，应：

1. 先明确下一阶段研究问题和验证目标。
2. 在当前实验完成节点**新建独立分支**，不要把下一阶段代码继续提交进此分支。
3. 对新论文遵循“先介绍论文与方法、获得确认、再适配代码和运行”的约定。

目前阶段结论应表述为“完成《实验2610》提出的门控放松、环境粒度及开源域泛化方法的探索性验证”，而不是“已证明学到了因果变量或跨环境不变的真实因果机制”。
