# 实验2610

## 1. 研究目标与阶段范围

针对4,769位有有效认知功能标签的老年人、19个预测特征，探索两项与V5双表示模型相关的问题：

1. **V1：特征门控过强约束是否阻碍预测？** 弱化因果图先验、不强制选5特征、使用连续门控与软稀疏，研究极化强度和最佳模型选择时机。
2. **V2：环境粒度应如何定义？** 比较12监测站点与东中西3地区，并测试跨站点/跨地区外部泛化。选择公开的VREx、RDM、GroupDRO算法核心模块进行CPU表格数据试用，了解其他风险不变性方法的表现。

## 2. 阶段1：建立可信的代码与数据基础

把旧V4/V5训练、评价和留一环境流程统一为`project/run.py`及`elderly_health`包。修复预处理泄漏、最佳权重恢复、Logits损失、图角色判定、样本ID和随机种子等问题；保留原脚本及历史结果以供追溯。

随机划分3337/716/716人，外部留出时各折仅对来源训练样本拟合预处理器。标签从原1/2统一成0/1；未改变调查量表的标签生成标准。研究分组：东部北京/山东，中部吉林/江西，西部广西/宁夏（须以正式调查设计为准）。

## 3. 阶段2：V1软门控与选模时机

原模型CausalGate给每个变量一个连续系数，分流到`z_c`和`z_s`；V5主头联合两种表示，额外包含`z_c`预测头、IRM(v11)、环境分类和HSIC。V1关闭图先验、改用均值软稀疏、不强制选五项，并比较不同极化系数。

针对最佳模型常在不变性约束未达到完整强度时产生的问题，设`selection_start_epoch=91`，只改变检查点选择窗口与早停计数，不改变损失函数。

| 极化权重 | 原策略AUC/AP      | 第91轮选模AUC/AP  | 观察     |
| -------- | ----------------- | ----------------- | -------- |
| 0        | 0.74046 / 0.36012 | 0.73820 / 0.35716 | 晚期稍低 |
| 3        | 0.73941 / 0.36096 | 0.73941 / 0.36096 | 一致     |
| 30       | 0.74406 / 0.39699 | 0.74203 / 0.39025 | 晚期稍低 |

数据：相同716人随机测试集、seed42。极化更强并不等于识别了因果因素，晚期选模也没有观察到明确增益。细节见复现指南。

## 4. 阶段3：V2环境粒度，逐级加严验证

- **随机划分**：在两套配置其他条件一致时，三地区配置比十二站点配置略优。
- **完整LOEO**：12次分别留出一个监测站点，两种环境定义优势几乎消失；普通MLP宏平均仍稍高。
- **LORO**：3次完整留出东、中、西各一地区，检验较大的分布偏移；这为开源算法提供了统一外部测试场景。

| 验证方式与主指标 |    MLP | V1/site（12站点） | V2/region（3地区） |
| ---------------- | -----: | ----------------: | -----------------: |
| 随机划分AUC      | 0.7495 |            0.7382 |             0.7438 |
| 随机划分AP       | 0.3790 |            0.3572 |             0.3758 |
| LOEO宏平均AUC    | 0.7175 |            0.7015 |             0.7028 |
| LOEO宏平均AP     | 0.3167 |            0.3072 |             0.3061 |
| LORO宏平均AUC    | 0.7155 |            0.7243 |             0.7244 |
| LORO宏平均AP     | 0.2836 |            0.3092 |             0.3101 |

*随机划分为相同的测试人群；LOEO为12站点等权宏平均，LORO为3地区等权宏平均，两种宏平均不能直接作同一难度尺度比较。*

**阶段认识：** 三地区环境可能在随机划分略有优势，但没有获得稳定的跨站点收益；V1/V2在LORO也极接近。留出站点`220202`（阳性率4.25%）时各方法AUC都很低，提示跨监测点异质性和少数类分布是实际困难。

## 5. 阶段4：三种开源方法试用

所有外部方法保留作者的核心目标，但将原图像/文本任务适配为19维表格、加权二元交叉熵、CPU并采用本项目训练/验证/测试划分。

| 算法                 | 论文/代码来源                                                   | 方法重点                                                    |
| -------------------- | --------------------------------------------------------------- | ----------------------------------------------------------- |
| VREx                 | [DomainBed](https://github.com/facebookresearch/DomainBed)       | 约束不同训练环境的**平均预测风险方差**                |
| RDM（WACV2024）      | [作者代码](https://github.com/nktoan/risk-distribution-matching) | 用多带宽核MMD匹配**最差风险环境和整体样本的损失分布** |
| GroupDRO（ICLR2020） | [作者代码](https://github.com/kohpangwei/group_DRO)              | 动态提高高损失训练组的权重，优化困难组                      |

### LORO三个留出地区AUC

| 方法          |             东部 |             中部 |             西部 |     三地区宏平均 |
| ------------- | ---------------: | ---------------: | ---------------: | ---------------: |
| MLP           |           0.6563 |           0.7407 | **0.7495** |           0.7155 |
| V1/site       |           0.6897 |           0.7388 |           0.7444 |           0.7243 |
| V2/region     |           0.6835 | **0.7418** |           0.7480 |           0.7244 |
| VREx          |           0.6877 |           0.7364 |           0.7441 |           0.7227 |
| **RDM** | **0.6982** |           0.7368 |           0.7477 | **0.7276** |
| GroupDRO      |           0.6733 |           0.7278 |           0.7382 |           0.7131 |

### LORO各地区等权平均的综合指标

| 方法          |          AUPRC↑ |             F1↑ |         Recall↑ |          Brier↓ |
| ------------- | ---------------: | ---------------: | ---------------: | ---------------: |
| MLP           |           0.2836 |           0.2880 |           0.3560 |           0.1485 |
| V1/site       |           0.3092 |           0.3408 |           0.4164 |           0.1439 |
| V2/region     |           0.3101 |           0.3517 |           0.4329 |           0.1429 |
| VREx          |           0.3035 | **0.3680** | **0.5265** |           0.1653 |
| **RDM** | **0.3127** |           0.3601 |           0.4266 | **0.1379** |
| GroupDRO      |           0.3007 |           0.3397 |           0.4150 |           0.1443 |

观察：**RDM**的宏平均AUC/AP/Brier在已试用模型中相对积极；**VREx**召回与固定阈值F1较高但Brier较差；**GroupDRO**没有整体AUC优势，不过留出中部的AUPRC 0.2316和Brier 0.1308较好。留出西部时GroupDRO最佳模型权重约97%集中在东部训练组，说明关注训练中困难环境不等于能保证预测新地区。
