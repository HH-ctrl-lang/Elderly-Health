# 任务2 第3步：东部受控复验

本轮目标：检验输入偏移调整和社会经济特征依赖两条解释。程序产出实验结果，不自动生成阶段研究结论。

在仓库根目录运行：

```bash
python project/src/analysis/task2/east_controlled_followup.py
```

默认东部、固定样本划分种子42、模型训练种子42/43/44，共24次MLP训练。默认CPU；历史300轮上限、patience=80、lr=3e-4、batch=64、pos_weight=3。需要中西部对照时使用 `--regions east central west`。使用现有环境和已有experiment1b函数，不安装新依赖。

输出：`outputs/analysis_2611/task2_step3_east_controlled_followup/`。目录已存在时拒绝覆盖；需要复跑可显式指定另一个 `--output`。不增加时间子目录。不保存逐人标签或预测。

预先固定八个条件：完整特征；社会经济组置零；三个不同随机三特征组置零；完整特征加权；社会经济组置零并加权；打乱权重的完整特征。标准化后置零，网络输入维数和参数量相同；随机三特征组不含社会经济变量且读取结局结果前固定。

所有条件预处理仅在来源训练集拟合，共用train/val/test。每个训练种子内重新训练未加权完整模型，不复用历史seed42预测冒充多次重复。训练和验证政策不变。密度比估计固定seed42，使用源地区和目标地区的无标签特征，交叉拟合、截尾、归一化沿用原实现。加权结果因此属于无监督目标域适配；不能用它声称纯域泛化。

阅读顺序：

1. `paired_seed_deltas.csv`：加权相对完整、加权相对打乱权重；社会经济屏蔽相对完整和三个随机屏蔽；加权后额外屏蔽的收益。
2. `repeat_summary.csv`：每项配对差异的均值、标准差、最小/最大值。三种子仅描述优化变化，不是置信区间；权重估计未重复，不覆盖它的不确定性。
3. `metrics.csv`：地区合并指标和四个站点指标。AUC/AUPRC/Brier一起看；0.5阈值指标仅作固定阈值记录。
4. `east_distribution_balance.csv` 与元数据中的ESS：确认分布是否真正接近、权重是否过度集中。

判读：若加权在多个种子改善，且优于打乱权重，才更支持分布调整的贡献。若社会经济屏蔽优于完整却未优于随机屏蔽，更像一般正则化或信息删减效应，不能认定该组为独特原因。若同时加权与屏蔽无额外收益，两条线索可能重叠，不能当作两个独立根因。随机屏蔽只有三组，是有限安慰剂。目标地区标签只用于最终描述，不能据此反复调参后继续把同一东部数据称为全新外部验证。
