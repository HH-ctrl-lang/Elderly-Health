# 任务五 第4步：下一篇论文的有限复现与预测筛选

论文：**Anti-causal domain generalization: Leveraging unlabeled data**，ICML 2026。

- 正式页面：https://proceedings.mlr.press/v306/saengkyongam26a.html
- 本轮核对版本：https://arxiv.org/pdf/2602.17187 ，v2，2026-06-17。
- 公式位置：§4–5的MIR/VIR，公式(9)(10)，§6.1的其他损失扩展。

## 这一步研究什么

在相同的线性二分类模型上比较：无环境约束、MIR、VIR。
MIR惩罚对来源环境均值变化敏感的系数方向；VIR针对来源环境协方差变化。
它不拆分隐空间，所以是稳定预测方法参考，不是新的因果解耦网络。

本轮是独立的公式实现及健康二分类适配，不是作者原实验或论文数值复现。
没有确认官方实现仓库，不把本代码称作作者代码。

## 固定方案

- 19维输入、数据版本、来源训练/验证划分、三个地区留一划分保持一致。
- 每折用8个来源训练站点作为环境。正则矩阵只读取来源训练特征及站点，不读取结局标签。
- 每站点按1/n计算均值和协方差；MIR为站点均值的协方差矩阵。
- VIR为协方差偏差矩阵D的D@D平均，不能误写为逐元素D**2。
- 预测损失为未加正类权重的二分类交叉熵，来源站点等权。
- 增加固定1e-5的系数L2以保证数值稳定；截距不受任何正则处罚。
- γ固定为0、0.01、0.1、1、10。MIR与VIR各自只按来源验证AUC选强度，完全并列选较小值。
- γ=0允许被选中。若它最合适，就如实报告不需要该约束，不强行选非零。
- 每折共9次低维凸优化，三折27次；不是27个神经网络训练。
- 所有优化都检查收敛和解析梯度。选参结束后才评价留出地区，不输出未选参数的目标成绩。

## 解释边界与停止条件

健康特征包含潜在原因、后果及类别编码，尚不能建立论文Setting 3.1所需反因果结构。
年龄等变量与因果方向、地区对结局的影响，不能由本实验自动解决。
原文平方损失下的鲁棒性定理也不能直接搬到此处的二分类适配。
原论文强调少量有标签环境加多个无标签环境，本轮来源站点都有标签，这是明确的数据设置差别。

所以本轮只检查预测收益，不以系数、正则矩阵或成绩改善推断因果特征。
历史MLP使用不同模型和正类权重，只作AUC/AUPRC参考，不直接比较Brier优劣。
主要看12站点等权宏AUC/AUPRC及地区退步；若没有值得关注的收益，结束此候选，不深入调参。
下一篇真正的解耦方法仍需单独筛选，不能把本方法混称为表征解耦。
