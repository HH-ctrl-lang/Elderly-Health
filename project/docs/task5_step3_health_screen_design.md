# 任务五 第3步：真实数据的一次有限筛选

本步骤只检查双块表征候选是否值得继续，不继续模拟实验调参。
它是受不变性思想启发的探索性改编，不是ICLR2025论文的原样复现。

## 本次对照

- 相同19维输入、来源训练集预处理、种子42、按地区留一验证。
- 两个编码块：预测块8维、残余块8维。分类只用预测块，两块一起重建输入。
- 两组模型结构相同，分别使用MMD权重0和0.1，不进行权重搜索。
- 损失为：加权预测BCE＋标准化输入重建MSE＋权重×类别条件MMD。
- MMD分别在来源阳性、来源阴性内部跨地区计算，避免直接将不同阳性率的混合分布强行对齐。
- 预测损失仍按来源地区均衡、地区内部自然类别比例抽样；MMD额外抽取同类样本。
- 预测块使用不可学习缩放的LayerNorm，减小任意整体缩小数值的空间；仍不保证避免坍缩或识别因果变量。
- 训练上限300轮、从91轮起按来源验证AUC选模、耐心80、学习率3e-4、正类权重3。
- 核函数固定；用潜空间维数归一化距离。模型初始化及共同训练轮次的所有批次索引哈希必须一致。
- 留出地区不参与任何训练、预处理拟合、带宽选择或选模。

## 评价与收束规则

主看12站点等权宏AUC/AUPRC，同时完整展示三个地区和每个站点。
先与相同结构、无MMD的对照比较，再看是否超过历史MLP的实际预测水平。
历史MLP只是参考，不是单因素对照，因为其结构与训练不同。
另报告原始及来源验证集截距调整后的Brier，避免把概率整体高低当成排序能力提升。

宏AUC提高约0.01仅作为值得关注的实用信号，不等于统计显著；还要看AUPRC和地区退步。
本轮不自动宣布通过，不挑选部分站点，不把0.1宣称为健康数据最优权重。
仅当真实任务改善值得关注时，再决定是否验证多个随机种子。
若缺乏明显收益，保留结果并停止该候选的深入调参。

## 必须保留的边界

类别条件对齐本身仍是一项额外假设，可能删掉有用信息。
预测块不等于已识别因果块，残余块也不保证只包含环境信息或与预测块独立。
本轮保留历史数值编码以固定输入，重建MSE属于有限筛选的实现选择，类别代码距离没有临床含义。
physical_activity来源及吸烟编码的既有疑问尚未由本步骤解决。
